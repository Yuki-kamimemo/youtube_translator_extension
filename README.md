# YouTube Live Chat Enhancer

## 概要

**YouTube Live Chat Enhancer** は、YouTubeのライブ配信やプレミア公開のチャットを日本語で追いやすくするChrome拡張機能です。チャット欄へのインライン翻訳と、動画プレーヤー上にコメントを流すフロー表示に対応しています。

主な機能は以下の通りです。

* **リアルタイム翻訳**: 外国語のチャットコメントを日本語に翻訳します。
* **フローコメント**: 原文・翻訳文・両方のいずれかを、動画プレーヤー上に横流し表示します。
* **Google翻訳 / LM Studio対応**: APIキー不要のGoogle翻訳と、ローカルLLMを使うLM Studioを切り替えられます。
* **隠しチャットiframe**: チャット欄を閉じていても、対応環境ではフローコメントを継続できます。
* **表示カスタマイズ**: フォント、サイズ、速度、透明度、縁取り、色、表示位置を調整できます。
* **ユーザー辞書 / スラング補正**: 固有名詞や配信向け表現を翻訳前に補正します。
* **NG機能**: 特定ユーザーやキーワードを含むコメントを非表示にできます。
* **プロファイル管理**: よく使う設定を保存して切り替えられます。

## インストール方法

1. このリポジトリのフォルダをダウンロード、またはクローンします。
2. Google Chromeで `chrome://extensions` を開きます。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選択します。
5. ツールバーに拡張機能アイコンが表示されれば完了です。

## 使い方

### コントロールボタン

YouTubeの動画ページを開くと、動画プレーヤー上に操作ボタンが表示されます。

* **翻訳ボタン**: チャット欄へのインライン翻訳をオン/オフします。
* **フローボタン**: 動画上にコメントを流す機能をオン/オフします。
* **設定ボタン**: 詳細設定パネルを開きます。

翻訳とフローのオン/オフ状態はタブごとに保存されます。ボタン位置は右上・左上・右下・左下から選べます。

### 翻訳設定

設定パネルの「基本設定」タブで翻訳サービスを選択できます。

* **Google翻訳**: APIキー不要で利用できます。
* **LM Studio**: `http://localhost:1234` のローカルAPIを使います。LM Studio側でローカルサーバーを起動し、モデルを用意してください。設定画面の「更新」でモデル一覧を取得し、選択したモデルを起動/停止できます。

#### TranslateGemma 4B（PC版）

翻訳専用モデルとして、[`mradermacher/translategemma-4b-it-GGUF`](https://huggingface.co/mradermacher/translategemma-4b-it-GGUF) の `Q4_K_S`（約2.38GB）を検証対象にしています。

1. Hugging FaceからQ4_K_SのGGUFを取得し、LM Studioへ登録します。
2. LM Studioの「My Models」でTranslateGemmaを開き、モデル設定の「Prompt Template」を上書きします。内容には、このリポジトリの `translategemma_lmstudio_template.jinja` をそのまま貼り付けて保存します。
3. LM Studioでローカルサーバーを起動します。
4. 拡張機能の「LM Studio」設定で「更新」を押し、TranslateGemmaモデルを選択します。
5. 「LM Studioモデルを起動」をオンにします。
6. 「TranslateGemma最適化: 適用中」と表示されることを確認します。

TranslateGemmaの公式GGUFテンプレートは、LM Studioのllama.cppエンジンが行うロード時の自動パーサー生成に対応していません。そのため上記の単純なGemmaテンプレートへ置き換え、拡張側から言語コードを含む非公式のLM Studio互換プロンプトを送ります。公式chat templateそのものではないため、正式な検証対象は上記Q4_K_Sとし、他の量子化形式は保証対象外です。TranslateGemma選択時は原文言語を自動判定し、言語を信頼できる精度で判定できない場合や、モデルが対応しない言語の場合は、フォールバック設定がオンならGoogle翻訳を使用します。他のLM Studioモデルを選択した場合は従来の汎用プロンプトが使われます。スマートフォン環境ではLM Studio連携は利用できません。

LM Studio翻訳に失敗した場合、設定によりGoogle翻訳へ自動フォールバックできます。翻訳結果は短時間キャッシュされ、同じコメントの重複翻訳を抑えます。

### ユーザー辞書

「単語登録」タブで、翻訳前に適用する置換ルールを登録できます。

```text
元の単語,翻訳後の単語
Holo,ホロ
Gura,ぐら
```

大文字小文字は区別されません。長い語から優先的に適用されます。

### フローコメント設定

フローコメントでは以下を調整できます。

* 流す内容: 翻訳文のみ、原文のみ、原文と翻訳文
* 速度、文字サイズ、透明度
* 上優先、下優先、ランダムの表示位置
* 上下余白、フォント、カスタムフォント
* 縁取りの太さと色
* 通常、メンバー、モデレーター、スーパーチャット、メンバー加入の文字色

スーパーチャット、スーパーステッカー、メンバー加入、メンバーシップギフトもフロー表示に対応しています。

### NG設定

「NG設定」タブで非表示条件を登録できます。

* **NGユーザー**: 完全一致した投稿者名を非表示にします。
* **NGワード**: コメント本文に含まれる単語で非表示にします。

### プロファイル管理

「プロファイル」タブで現在の設定を名前付きで保存できます。配信者や用途ごとに表示設定・辞書・NG設定を切り替えたい場合に使います。

## 対応コメント種別

| 種別 | フロー表示 | インライン翻訳 |
|---|---|---|
| 通常チャット | ○ | ○ |
| スーパーチャット | ○ | ○ |
| スーパーステッカー | ○ | — |
| メンバー加入 | ○ | ○ |
| メンバーシップギフト購入 | ○ | ○ |
| メンバーシップギフト受け取り | ○ | ○ |

## 技術的な詳細

この拡張機能はManifest V3で動作します。

* `manifest.json`: 権限、Content Script、Service Workerの定義。
* `content_script.js`: YouTube動画ページ側の初期化、プレーヤー上UI、設定パネル、隠しチャットiframe、フロー描画の受信処理。
* `chat_observer.js`: `live_chat` iframe専用の軽量スクリプト。チャット監視、NG判定、翻訳キュー、親ページへのフロー用データ送信を担当。
* `background.js`: Google翻訳 / LM Studio呼び出し、翻訳キャッシュ、モデル一覧取得、モデル起動/停止、メッセージ中継。
* `flow.js`: フローコメントのレーン制御、描画、XSS対策済みHTML再構築。
* `translation.js`: 翻訳スキップ判定。
* `popup.html` / `popup.js`: 設定パネルUIと保存処理。
* `content_script.css`: プレーヤー上UI、設定パネル、フローコメントのスタイル。
* `slang_dict.json`: YouTubeチャット向けスラング補正辞書。

メモリ使用量を抑えるため、`/watch` ページと `/live_chat` iframeで読み込むスクリプトを分離し、設定パネルは閉じると破棄されます。翻訳キュー、翻訳済みDOM、重複コメントID、翻訳キャッシュにも上限を設けています。
