# YouTube Live Chat Enhancer

## 概要

**YouTube Live Chat Enhancer** は、YouTubeのライブ配信やプレミア公開のチャットをより楽しむための多機能拡張機能です。海外の配信をリアルタイムで楽しみたい時や、たくさんのコメントを追いかけたい時に役立ちます。

主な機能は以下の通りです。

*   **リアルタイム翻訳**: 外国語のチャットコメントを日本語に自動で翻訳します。
*   **フローコメント**: 翻訳したコメントや元のコメントを、ニコニコ動画のように動画プレーヤー上に流して表示します。
*   **高度なカスタマイズ**: コメントの表示スタイル（フォント、色、速度など）を自由に変更できます。
*   **NG機能**: 特定のユーザーやキーワードを含むコメントを非表示にできます。
*   **プロファイル管理**: よく使う設定を保存し、いつでも切り替えることができます。

## インストール方法

1.  この拡張機能のフォルダをダウンロードします。
2.  Google Chromeを開き、アドレスバーに `chrome://extensions` と入力して拡張機能管理ページを開きます。
3.  ページの右上にある「デベロッパーモード」をオンにします。
4.  「パッケージ化されていない拡張機能を読み込む」ボタンをクリックし、ダウンロードした拡張機能のフォルダを選択します。
5.  ツールバーに拡張機能のアイコンが表示されればインストール完了です。

## 使い方

### 1. コントロールボタン

YouTubeの動画ページ（ライブ配信またはプレミア公開）を開くと、動画プレーヤー上にコントロールボタンが表示されます。ボタンはYouTubeの操作バーと連動して表示・非表示が切り替わります。

*   **翻訳ボタン**: チャット欄内でのインライン翻訳のオン/オフを切り替えます。
*   **フローボタン**: 動画上にコメントを流す機能（フローコメント）のオン/オフを切り替えます。
*   **設定ボタン（歯車）**: 詳細な設定パネルを開きます。

ボタンの表示位置（右上・左上・右下・左下）は設定パネルから変更できます。

### 2. 基本的な設定

設定ボタンを押すと設定パネルが表示されます。このパネルはドラッグして好きな位置に移動でき、端をドラッグしてリサイズもできます。

#### 翻訳サービスの設定

*   **翻訳サービス**: 使用する翻訳エンジンを選択します。
    *   **Google翻訳**: APIキー不要で手軽に利用できます。
    *   **LM Studio (ローカルLLM)**: ローカルで動作する LLM による翻訳です。事前に LM Studio のインストール、モデルのダウンロード、APIサーバーの起動が必要です（既定エンドポイント: `http://localhost:1234`）。GPUを節約するため、設定パネルからモデルの起動/停止を制御できます。登録済みモデルは「更新」ボタンで読み込み、一覧から選択できます。
*   **フォールバック**: 翻訳エラーが発生した場合、自動でGoogle翻訳に切り替えるかを選択できます。

#### ユーザー辞書

翻訳前に適用する置換ルールを登録できます。配信者名・ゲーム内用語・コミュニティ固有の略語などを登録しておくと、誤訳を減らすことができます。

*   書式: `置換前,置換後` を1行に1つずつ入力します。
*   長い語から優先的に適用されます。

### 3. フローコメントの詳細設定

フローコメントを有効にしている場合、その表示方法を細かく設定できます。

*   **流す内容**: 「翻訳文のみ」「原文のみ」「原文と翻訳文の両方」から選択します。
*   **速度**: コメントが画面を流れる速さを秒単位で設定します（デフォルト: 8秒）。
*   **サイズ・透過度**: フォントの大きさ（px）と透明度を調整します。
*   **表示方法**: コメントが画面の上から・下から・ランダムな位置に表示されるかを選べます。
*   **マージン**: 画面の上下にどれくらいの余白を設けるかを設定します。
*   **フォント**: コメントのフォントを選択したり、好きなフォント名を直接入力したりできます。
*   **縁取り**: 文字の縁取り色と太さを設定できます。
*   **色設定**: 通常・メンバー・モデレーター・スーパーチャットなど、投稿者の種類に応じてコメントの色を個別に設定できます。

### 4. NG設定

見たくないコメントを非表示にできます。

*   **NGユーザー**: 非表示にしたいユーザーの名前を1行に1人ずつ入力します。
*   **NGワード**: 非表示にしたい単語を1行に1つずつ入力します。

### 5. プロファイル管理

配信者や視聴するコンテンツに合わせて設定を保存し、簡単に切り替えることができます。

*   **保存**: 現在の設定に名前を付けて保存します。
*   **読み込み**: 保存したプロファイルを選択して、設定を一度に読み込みます。
*   **削除**: 不要になったプロファイルを削除します。

## 対応コメント種別

| 種別 | フロー表示 | インライン翻訳 |
|---|---|---|
| 通常チャット | ○ | ○ |
| スーパーチャット | ○（専用スタイル） | ○ |
| メンバー加入 | ○（専用スタイル） | ○ |
| スーパーステッカー | ○ | — |
| メンバーシップギフト | ○ | ○ |

## 技術的な詳細

この拡張機能は、以下のファイルで構成されています。

*   `manifest.json`: 拡張機能の基本的な定義ファイル。
*   `content_script.js`: YouTubeのページに挿入されるメインスクリプト。チャットの監視・DOM操作・UI生成・翻訳キュー管理などの中核処理を担います。
*   `background.js`: Service Workerとしてバックグラウンドで動作し、翻訳API呼び出し・翻訳キャッシュ管理・タブ間メッセージ中継を行います。
*   `flow.js`: 動画プレーヤー上にコメントを流すフローコメント（弾幕）機能の実装です。
*   `translation.js`: 翻訳スキップ判定やインライン表示などのユーティリティ関数群です。
*   `popup.html` / `popup.js`: 詳細設定パネルのUIとロジックを担います。
*   `content_script.css`: ページに挿入するUI（フローコンテナ・オーバーレイボタン・設定パネル）のスタイルを定義します。
